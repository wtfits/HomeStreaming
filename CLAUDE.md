# HomeStreaming — notes for Claude

Personal media server: Go 1.26 single binary (`cmd/homestreaming`) + Preact/TypeScript web client (`web/`, embedded via `go:embed`). Design contract: `docs/DESIGN.md`, `docs/API.md`, `docs/ROADMAP.md` (Phase 1 = implemented MVP).

## Commands

- Go tests (unit + API, uses real ffmpeg; ~1 min): `go test ./...` — race check: `go test -race ./...`
- One package / test: `go test ./internal/library -run TestNamingFixtures`
- Web build (type-check + Vite + Chrome-79 ES/CSS check): `cd web && npm run build`
- Web type-check only: `cd web && npx tsc --noEmit`
- E2E (builds everything, generates media, runs Playwright desktop/iPhone/webOS): `./scripts/e2e.sh` — screenshots land in `e2e/test-results/shots/`
- Lint: `gofmt -l internal cmd` (must be empty), `go vet ./...`
- Cross-compile release archives: `make dist`

## Gotchas

- `go.mod` says `go 1.26.0`; with `GOTOOLCHAIN=auto` the toolchain downloads itself. Keep `CGO_ENABLED=0` builds working (pure-Go SQLite `modernc.org/sqlite`).
- `web/dist/.keep` must stay committed or `go:embed all:dist` fails; `npm run build` cleans only `dist/assets`.
- The LG A1 TV runs webOS 6 (Chromium 79): no flex `gap`, `aspect-ratio`, `inset`, `:focus-visible`, `:is()` in CSS; Vite target `chrome79,safari13`. `scripts/check-es-target.mjs` enforces this on every build.
- Test media is generated by `internal/testutil` (cached in `$TMPDIR/homestreaming-testmedia-<TreeVersion>`); bump `TreeVersion` when changing the tree. Expected scan: 4 movies, 5 series, 8 episodes.
- Naming fixtures in `internal/library/naming_test.go` come from the real library (`F:\torrent`); keep them passing.
- Decision engine truth table: `internal/stream/decide_test.go`; reason codes are part of the API.
- Playwright in cloud sessions uses the preinstalled browsers: `PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers` (set by `.claude/hooks/session-start.sh` and `scripts/e2e.sh`).
- The headless Chromium decodes H.264/AAC/VP9/Opus but not HEVC/AC-3 — that is what exercises the remux/transcode paths in E2E.
- In this sandbox, Docker builds need the proxy CA (`/root/.ccr/ca-bundle.crt`) injected into build stages; never commit it.

## User's setup (design inputs)

Windows 11 PC (Ryzen 9 7950X, RTX 4090 → NVENC), media `F:\torrent`, LG OLED65A16LA (webOS 6, no DTS), iPhone 14 Pro (iOS 27), ISP behind CGNAT with 10 Mbps upload → Tailscale for remote access, 6 Mbps remote cap. Deployment guide: `deploy/windows.md`.
